# 大地图探险 · 多人联机小游戏

> 在 7000×7000 的广袤大陆上，和朋友一起奔跑、收集、躲避、比得分。

## 在线体验

**https://zqy351.github.io/**

打开即玩，无需安装。房主点「创建房间」，把 5 位房间码发给朋友，朋友点「加入房间」输入房间码即可同场游玩。

## 玩法

- **移动**：WASD / 方向键；手机端左下角虚拟摇杆
- **金币**（金色圆点）：+1 分
- **宝石**（蓝色菱形）：+5 分
- **闪电**（黄色图标）：4 秒加速
- **史莱姆**：会追人的绿色小怪，被碰到丢 3 分并短暂无敌
- **地形**：草原 / 森林 / 沙漠 / 雪原 / 湖泊 / 山脉，不同地形移速不同（森林慢、沙漠略慢）
- **表情短语**：右下角按钮发送气泡短语，队友都能看到
- 道具被捡走后 25 秒会在原地重生

## 多人联机

- 架构：PeerJS（WebRTC 点对点）+ 房主权威同步（房间码 = 房主 ID）
- 房主负责模拟史莱姆、验证拾取、广播全局状态（10Hz）；客户端平滑插值渲染
- 内置多路 STUN + 免费 TURN 中转，跨网络、国内网络联机成功率更高
- 房间随房主退出而关闭；网络波动自动重连

## 技术栈

- 单文件 HTML5 + Canvas 2D，无构建、无依赖（仅 PeerJS CDN）
- 地图固定种子程序化生成，所有玩家地图完全一致
- 托管于 GitHub Pages
